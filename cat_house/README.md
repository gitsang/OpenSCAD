# 3030 铝型材猫屋 —— 设计与装配说明

> 模型文件：`cat_house.scad`　｜　自检脚本：`verify.py`　｜　
> 预览/导出：`openscad cat_house.scad` / `openscad -o cat_house.stl cat_house.scad`

整机 **1200 × 600 × 2000 mm**（120×60×200 cm），全部用 **3030 T 型槽铝型材** +
**三角角码** 连接，围板用 **木板 / 透明亚克力**，层板与背板用木板。

---

## 1. 分层方案

| 层 | 高度区间 (mm) | 净高 | 用途 | 四面围板 | 门 |
|---|---|---|---|---|---|
| **L0** | 0 – 500 | 452 | **猫厕所** | 全部 **木板**（不透光） | 2 扇木门，左扇开 Ø230 猫洞 + 木翻板 |
| **L1** | 500 – 1000 | 452 | **自动喂食机 + 饮水机** | **透明亚克力** | 2 扇亚克力门 |
| **L2** | 1000 – 1500 | 452 | **娱乐**（跳台 / 磨爪板 / 玩具球） | **透明亚克力** | 2 扇亚克力门 |
| **L3** | 1500 – 1955 | 407 | **休息 · 观景**（猫窝 / 顶灯） | **透明亚克力** | 2 扇亚克力门 |

* 背板：**全部用木板**（含 L1~L3，符合「背板用木板」的要求）。
* 顶板：木板 1200 × 600 × 15，直接盖在顶层圈梁上，整机总高正好 2000。
* 每层前脸都是 **2 扇对开门**，铰链在左右两侧，可以只开一边（例如只开 L1 右扇加水）。

**猫的活动动线**：屋外 → L0 木门上的猫洞 → L0 猫砂盆 →
踩 跳台① → 从 L1 层板猫洞钻上去 → L1 吃饭喝水 →
跳台② → L2 玩耍 → 跳台③ → L3 睡觉看风景。
层板上的 Ø200 猫洞和 3 个木跳台都排在剑麻爬柱旁边，柱身兼作磨爪器。

## 2. 结构

```
       ┌────────────────────────────┐  z = 2000  木顶板 15
       │  L3  休息 · 观景（亚克力） │  z = 1955  顶层圈梁
       ├────────────────────────────┤  z = 1545  木层板 15
       │  L2  娱乐（亚克力）        │  z = 1530  圈梁
       ├────────────────────────────┤
       │  L1  吃饭喝水（亚克力）    │  z = 1045  木层板
       ├────────────────────────────┤
       │  L0  猫厕所（全木板）      │  z = 545   木层板
       └────────────────────────────┘  z = 0     底圈梁
```

* **4 根通高腿**（1985 mm）+ **5 道水平圈梁**（z = 0 / 500 / 1000 / 1500 / 1955）。
* 圈梁长边（前后）= 1140 mm，短边（左右）= 540 mm，两端顶在腿的内侧面。
* 每道圈梁的 4 个内角各放 **1 个 3030 三角角码**（45×45×8，2 个 M8 沉孔），
  平放在角上、贴着两根圈梁的内侧面，共 **20 个**。
* **层板**是 1200 × 600 整板，四角挖掉 31 × 31 的方缺口让开腿，
  直接搭在圈梁上表面 —— 四边全支撑，不用额外层板托。
* **围板**的外表面与型材外表面**齐平**。所以从侧面看整机是
  一条平整的立面：铝型材带 → 木板带（层板侧边）→ 亚克力带 → 再一层圈梁……
* **门是「内嵌式」**：门平面在 y ∈ [0, t]，正好填满两根腿之间的洞口，
  与型材前表面齐平。

### ⚠ 两个容易踩的坑（模型里已经处理，自己改的时候注意）

1. **不要把 3030 截面等比放大当成挖缺刀具。**
   3030 截面中间是空腔（Ø6.8 中心孔 + 4 条槽腔），以截面中心缩放会把
   空腔一起放大，结果腿的实体反而露出一圈细条与层板干涉，而且缩小后的
   中心孔会在被挖掉的区域里留下一块「孤岛板」。
   → 用外接方形挖缺（`NOTCH = P + 1`），简单、正确，实做只要两刀。

2. **内嵌门的铰链轴必须落在门洞的「前-外角」上。**
   本模型把门做在 y ∈ [0, t]、x ∈ [腿内侧] 的洞口里，铰链销放在
   `(x = 门的外侧边, y = -6)`。`y = -6` 是让合页轴套（半径 6）完全落在
   型材前表面之外，不插进腿里；同时门体绕它转动时最靠内的点始终是
   x = 31.5 > 30（腿的内表面），所以 0°~175° 全程不会撞框。
   `verify.py` 里同时做了**正向**（不撞）和**负向**（把销内移 15 mm 必须撞）
   两组测试 —— 只有负向也通过，才能说明这个检查不是空的。

## 4. 装配顺序建议

1. 先做 **底圈 + 4 条腿 + 三角角码** → 立起来（此时最好有人扶）。
2. 由下往上，一层一层地装：**装圈梁 → 铺该层木层板 → 装该层围板 → 装门**。
3. 围板先装左右、再装背板，最后装门（门缝左右各 1.5 mm，中缝 3 mm）。
4. 剑麻爬柱最后立起来，用柱脚法兰拧在 L0 层板上；柱身穿层板处的 Ø130 孔。
5. 3 个木跳台（300 × 240）从侧面拧在爬柱上。
6. 全部装完再调整 4 个脚垫，让门缝均匀。

**实用小改**：L0 是全封闭的，建议在 L0 背板上开 2 排 Ø30 通风孔
（外面加一块挡板做成「错位百叶」，仍然不透光），否则夏天猫砂味会积在
箱子里。模型里没有画，属于按需现场开孔。

## 5. 命令

```powershell
$sc = 'C:\Program Files\OpenSCAD\openscad.exe'

# 预览 / 导出
& $sc 'cat_house.scad'
& $sc -o 'cat_house.stl' 'cat_house.scad'

# 开门状态预览
& $sc -D 'DOOR_ANG=50' 'cat_house.scad'

# 出透视图
& $sc -o 'preview.png' --imgsize=1400,1800 --autocenter --viewall `
       --camera=0,0,1000,62,0,28,2600 --projection=p 'cat_house.scad'

# 几何 / 运动学自检（需要 FreeCAD 自带的 python，含 numpy）
& 'C:\Program Files\FreeCAD 1.1\bin\python.exe' 'verify.py'
```

`verify.py` 会检查：

1. 3030 截面面积（单独挤 100 mm 量体积）与手算公式对比；
2. 整机包围盒 = 1200 × 600 × 2000，整壳体积 = 型材 + 各板 + 角码 的手算和；
3. 角码 / 层板 / 围板 / 门 / 顶板 / 箱内物 **两两求交体积 ≈ 0**；
4. 门 0~175° 扫掠不撞框，并做**负向对照**证明该检查有效；
5. 层板猫洞 / 爬柱孔用探针验证确实挖空，并在实心区做同尺寸对照。
