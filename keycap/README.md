# 笔记本式 1u 薄键帽 —— 参数化模型

> 模型：`keycap.scad`　｜　自检：`verify.py`（`run_verify.bat`）　｜　
> 预览：`openscad keycap.scad`　｜　导出：`openscad -o keycap.stl keycap.scad`

单只 **1u 笔记本键帽**，用于「键盘架在三脚架上」那类低矮薄型键盘的替换键帽。
与机械键帽不同：笔记本键帽是**上大下小的倒锥台**（侧裙向外张开），顶面几乎平，
靠底面的**卡勾 + 卡槽**勾住剪刀脚支架，中央由橡胶碗顶起。

---

## 1. 外形

```
        顶面 18.0 x 18.0 ,  R2.19         ← 指窝 R60 / 深 0.30
       ╱                      ╲
      ╱  壁厚 1.4 (顶板同厚)    ╲          z = 5.5  总高
     ╱                          ╲
    └──────── 15.6 x 15.6 ───────┘         z = 0    开口
        侧裙外张 12.3°  →  底面坐床, 无超过 45° 的悬垂
```

| 项 | 值 |
|---|---|
| 顶面 / 底面外缘 | 18.0 × 18.0 / 15.6 × 15.6 mm |
| 总高 | 5.5 mm |
| 侧壁 & 顶板厚 | 1.4 mm |
| 底面 / 顶面圆角 | R1.9 / R2.19 |
| 顶面指窝 | 球面 R60，深 0.30 mm（凹坑直径 ≈ 12 mm） |
| 内腔 | 12.8 × 12.8 → 14.59 × 14.59 mm，顶板下表面 z = 4.1 |
| 单只体积 / 质量 | ≈ 754 mm³ ≈ **0.78 g**(ABS) / 0.90 g(PC) |

**打印朝向**：底面朝下，**不需要支撑**。侧裙是 12.3° 外张（远小于 45°），
顶板是 15 mm 的桥接，橡胶碗坑只有 0.25 mm 深。

---

## 2. 底面接口（剪刀脚）

```
        ← 后 y>0            y<0 前 →
   ┌──┬──────┬──┐        卡槽 (通孔) x2        z∈[1.4, 3.2]
   │  ▓▓▓▓▓▓  │        卡勾竖块 x2           z∈[1.0, 3.2]
   │          │        卡唇(上) x2           z∈[3.2, 4.3]
   │  ╭────╮  │        橡胶碗定位坑 Ø8      z∈[4.1, 4.33]
   │  │ ●● │  │
   └──┴──────┴──┘
```

| 特征 | 位置 | 作用 |
|---|---|---|
| 卡勾 ×2（前） | x = ±4.4，宽 3.0 | 竖块 + 顶部内伸卡唇，形成 1.4 × 2.2 mm 的**卡入口袋** |
| 卡槽 ×2（后） | x = ±4.4，宽 3.0 | 通孔，剪刀脚后轴销滑入 |
| 橡胶碗坑 | 中心 Ø8，深 0.2 | 橡胶碗触点定位 |

**卡勾的建法（关键）**：卡勾是 `intersection(长方体, 外壳)` 得到的，
所以勾的外表面**天然与侧裙斜面齐平** —— 不会在外表面留下台阶，也不会在
1.4 mm 的薄壁里留下一条 < 0.2 mm 的薄片。卡勾必须在**挖内腔之后**再并回去，
否则会被内腔切掉（`keycap.scad` 里 `union { difference {...} hooks }` 就是这个原因）。

## 3. 参数

所有尺寸都在 `keycap.scad` 顶部，直接改即可：

```openscad
TOP_W  = 18.0;   // 顶面边长
BOT_W  = 15.6;   // 底面外缘边长
H      = 5.5;    // 总高
WALL   = 1.4;    // 壁厚 / 顶板厚
R_BOT  = 1.9;    // 底面圆角
DISH   = 0.30;   // 顶面指窝深
R_SPH  = 60.0;   // 指窝球面半径
HOOK_* / SLOT_* / PAD_*        // 底面接口
```

派生量（斜率、内腔尺寸、圆角）会自动跟着变；改成 17 × 17 / 高 4.5 这类
「超薄笔记本」规格也只需改上面 4 个数。

> ⚠ `WALL` 决定顶板厚度，而指窝 `DISH` 和橡胶碗坑 `PAD_D` 都从顶板里挖料：
> 中心最薄处 = `WALL - DISH - PAD_D`。默认 = 1.4 - 0.30 - 0.20 ≈ 0.9 mm（约 4 层 @0.2）。
> 想让顶板更结实就先加 `WALL`。

## 4. 自检

```
run_verify.bat          # 输出写 _verify_out.txt
```

`verify.py` 做四类检查（共 20 项）：

| 类别 | 内容 |
|---|---|
| 0 装置自检 | 确认 `use <keycap.scad>` 不会连带渲染文件顶层的 `keycap();` |
| 1 外形/体积 | 包围盒必须 18 × 18 × 5.5；体积必须等于解析公式（圆角方锥台 − 内腔 − 指窝 − 碗坑 − 卡槽 + 卡勾） |
| 2 特征探针 | 11 个探针盒判断顶板 / 内腔 / 指窝 / 碗坑 / 侧壁 / 卡勾 / **卡唇下口袋** / 卡槽 是实心还是空的 |
| 3 连通性 | 解析 STL 按共享边做并查集 —— 必须**单一连通体**（专门防卡勾变孤岛） |
| 4 负向对照 | 逐条关掉 `show_dish/pad/hook/slot`，对应探针必须**真的翻转**；另喂一个故意断开的模型给连通性检查，必须报 2 块 |

两个刻意的设计选择，都是被坑过的：

* **探针用 `difference` 而不是 `intersection`。**
  CGAL `Nef_3` 在两个互不相交的实体上求交会断言失败
  （`SNC_external_structure.h:1152`）并**悄悄返回垃圾几何**，rc 还是 0。
  「盒 − 模型」是稳定操作：空区 coverage = 0%，实心区 = 100%。
* **每个检查都配一条负向对照。**
  只做正向检查时，一个写成 `coverage > -1` 的空检查也会一路 PASS。

## 5. 后续可加

* **三脚架转接件**：本模型只覆盖键帽。键盘本体架到三脚架上还需要一块
  1/4"-20 云台螺丝的转接板（底板 + 螺孔 + 键盘挂点），可以在这个项目里
  再加一个 `tripod_mount()` 模块。
* 多键帽阵列（整排键帽一次性排版打印）—— 在顶层的 `keycap();` 换成
  `for (x = [0:19]) translate([x * 19, 0, 0]) keycap();` 即可。
